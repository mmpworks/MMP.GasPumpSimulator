# Articles

Six standalone HTML articles about the simulator. Open any file in a browser. Diagrams render from a public CDN copy of Mermaid 11.16.1, so the pages need a network connection for the pictures and nothing else.

| # | File | Topic |
|---|------|-------|
| 1 | `01-patterns.html` | Gas pump patterns: workers, mailboxes, messages, the three dispatch strategies |
| 2 | `02-security-and-audit.html` | Assets, attackers, the token, the ledger, custody, and the CAP trade at each wire |
| 3 | `03-fuel-detergent.html` | Adding a detergent additive as a bolt-on: the two seams and their tests |
| 4 | `04-receipts-lines-video.html` | Charge lines to the bank, the receipt window, and a capability listener |
| 5 | `05-one-perfect-sale.html` | One sale followed piece by piece through both programs |
| 6 | `06-waiting-without-a-thread.html` | How MMP.AsyncProxy waits without a thread, down to the IL |

Article 6 also lives in MMP.AsyncProxy as course chapter 10 (`docs/course/10-waiting-without-a-thread.md`).

Each article's footer names the commit it describes. Later commits may have moved a line or two.
